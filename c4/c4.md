# 4. 데이터프레임의 세계로
## 4.1. 데이터프레임 이해하기
- 데이터프레임(dataframe): 행과 열로 구성된 사각형 모양의 표
    - 열(column): 속성
    - 행(row): 정보
- 데이터가 크다 = 행 or 열이 많다
    - 열이 많은것이 중요
    - 행은 늘어나도 분석에 들이는 노력은 달라지지 않음

## 4.2. 데이터프레임 만들기
- pandas: 데이터프레임을 가공할 때 사용하는 패키지
- 데이터프레임 선언: 중괄호({})를 입력받은 다음 변수명, 콜론(:), 변수에 넣을 값을 차례로 입력
- 데이터프레임 변수 바로 뒤에 `'['컬럼명']'`을 붙이면 특정 컬럼만 조회 가능
```python
# 패키지 로드
import pandas as pd

df = pd.DataFrame({
    'name': ['a','b', 'c', 'd'],
    'eng': [90, 80, 70, 60],
    'math': [50, 60, 100, 20]
})
df
```

### csv 파일

- csv 불러오기: pd.read_csv(’파일명’)

```python
#csv파일 불러오기
df_csv_exam = pd.read_csv('./Data/exam.csv')
df_csv_exam
```

- csv 저장: df.to_csv(’저장경로’, [index=False])
    - index=False: 첫번째 열의 인덱스 없이 저장

```python
# csv 파일로 저장하기
df_midterm = pd.DataFrame({'english' : [90, 80, 60, 70],
                           'math'    : [50, 60, 100, 20],
                           'nclass'  : [1, 1, 2, 2]})
df_midterm

df_midterm.to_csv('./Data/output_newdata.csv')
df_midterm.to_csv('./Data/output_newdata.csv', index=False)
```
